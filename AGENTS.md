# PerfumeShots Content Update Guidelines

These instructions govern future brand, perfume collection, discovery, and stockist updates. Follow the user's latest explicit direction whenever it differs from an older preference here.

## Before editing

- Inspect the current brand, perfume, discovery, and stockist records before changing anything.
- Match existing perfumes by brand and name, accounting for accents, apostrophes, punctuation, and concentration suffixes. Do not create duplicates just because spelling or formatting differs.
- A perfume name not found in that brand's collection is a new entry.
- Change an existing perfume's name, status, notes, year, or other details only when the user explicitly asks to change that existing entry. A supplied list of names alone is not permission to silently rename or remove existing records.
- If removing a label such as “standalone,” preserve the perfume entry unless the user explicitly asks to remove the perfume itself.
- If the requested change is ambiguous or would overwrite conflicting information, make the safe edits that are clear and ask about only the unresolved item.

## Perfume collection records

- Use the established record shape: release year, perfume name, optional collection name, genre, and 2–4 prominent notes.
- Sort entries by release year, newest first. Keep entries with unknown years after dated entries unless the user specifies another ordering.
- Preserve the supplied perfume spelling and diacritics. Use normal perfume-name casing; do not force perfume names into all caps.
- Display collection names in full capitals. Keep collection labels separate from perfume names.
- Treat distinct concentrations as separate entries when the user provides them as distinct releases. Use the concentration in the name as requested (for example, “Name Eau de Parfum”); do not invent a concentration.
- Put a discontinued marker on the perfume's own row, at the end of the row, and keep it searchable.
- Use the user's exact requested status label for ownership or format changes. Do not convert one status into another unless asked.

## Discoveries on the homepage

- Keep homepage discoveries separate from a brand's full perfume collection.
- Assign each discovery to the correct brand. A new brand launch must not be attributed to another brand just because it was found at that brand's retailer.
- Preserve the user's date and retailer information. Do not invent missing values.
- For multiple-perfume launches, list the individual perfume names and descriptions as provided. Keep any banner associated only with its own launch entry.

## Brand directory and stockists

- Add only brands the user asks to include. The directory is intentionally curated; do not add unrelated designer or local brands without the user's direction.
- Prefer the brand's official website for brand and perfume facts. Treat user-provided data as the requested content; do not silently replace it with third-party data. If the user asks for verification, check the official source first and report unresolved conflicts.
- Add an official website link to a brand profile when available.
- Associate a brand with the stockist the user identifies. Do not create a new store or shopping-centre group for a single brand when it belongs under an existing retailer.
- A brand can be listed without a Singapore address when the user wants to include it as a direct-order brand; do not invent a local stockist.
- Format profile addresses consistently: bold building name on one line, address on the next line, with the address linked to that shop's Google Maps location.
- Only link a brand to a retailer or location group when that association is accurate and requested or supported by the existing records.

## Editing and publishing

- The CMS has been removed. Make future content changes in the repository's current data structure and preserve the existing site behavior.
- Keep content edits focused. Do not change the page design, application logic, stockist associations, or unrelated records during a content update.
- After editing, review the changed record and its visible context for duplicates, ordering, spelling, and links. Do not add or run tests unless the user asks.
- The connected Cloudflare deployment publishes repository changes automatically; do not make unrelated Cloudflare configuration changes for ordinary content updates.
